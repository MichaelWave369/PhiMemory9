## R0.1 expression contract

Input is a Python list of synthetic metadata dictionaries, a project scope,
a set of context tags, and a limit 0–9. Strict enums and exact field sets
are required. Missing/unknown fields and duplicate IDs fail closed. No
payload text is accepted. Explicit suppression wins over activation. Only
public, clean, safe_to_use, source-linked, high/verified, non-speculative
candidates can be eligible for a preview. All other consent classes hold;
no consent token is accepted at this rung. Source references are declared
metadata, not verified evidence. Scope mismatch blocks even a perfect match.
Ranking is lexicographic by ID, not a relevance or importance score.
The limit is a maximum, not proof of minimum sufficient recall.
No output includes meaning, source refs, context tags or policy payloads.
Do not persist preview IDs for private data; fixtures only. A preview is
not an ExpressionEvent, an authorization, a signed receipt or a repair.
